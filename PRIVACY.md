# Política de Privacidad / Privacy Policy

**Última actualización / Last updated:** Octubre 2026

---

## Español

En **Super Downloader Manager**, valoramos y respetamos profundamente tu privacidad. Esta política describe cómo se maneja tu información al utilizar nuestra aplicación.

### 1. Sin recopilación de datos personales (No Telemetry)
* **Super Downloader Manager no recopila, almacena ni comparte ningún tipo de información personal identificable.**
* No incluimos herramientas de telemetría de terceros, rastreadores analíticos ni publicidad.
* Tu historial de descargas, los enlaces agregados y los archivos descargados permanecen exclusivamente en tu dispositivo local.

### 2. Procesamiento y almacenamiento local
* Todos los ajustes de configuración, categorías, colas y credenciales de autenticación necesarias para descargas privadas se guardan de forma cifrada o local en tu equipo.
* Ningún dato de configuración se envía a servidores externos ni a los desarrolladores.

### 3. Conexiones de red
* La aplicación únicamente establece conexiones de red hacia las URLs y servidores que tú mismo especificas explícitamente al añadir una descarga.
* **Comprobación de actualizaciones:** Al verificar actualizaciones, la aplicación realiza una petición pública anónima a la API de GitHub (`https://api.github.com/repos/Releases-florperial/Super-Downloader-Manager/releases/latest`) para comprobar si existe una versión más reciente. En esta consulta no se envía ninguna información personal ni identificadores de tu equipo.

### 4. Seguridad
Nos comprometemos a mantener el código seguro, limpio y transparente. Las descargas e instaladores oficiales se firman y se publican con sus sumas de verificación criptográficas (hashes MD5/SHA) para asegurar que no han sido alterados.

## English

At **Super Downloader Manager**, we deeply value and respect your privacy. This policy outlines how your information is handled when using our application.

### 1. No Personal Data Collection (Zero Telemetry)
* **Super Downloader Manager does not collect, store, or share any personally identifiable information.**
* We do not include third-party telemetry frameworks, analytic trackers, or advertising scripts.
* Your download history, queue lists, and downloaded files remain strictly on your local device.

### 2. Local Processing & Storage
* All settings, download queues, categories, and authentication credentials needed for private downloads are stored locally on your machine.
* No configuration data is ever transmitted to external servers or the developers.

### 3. Network Connections
* The application only establishes outbound network connections to the URLs and servers you explicitly request to download from.
* **Update Checks:** When checking for updates, the app performs an anonymous, public request to the GitHub Releases API (`https://api.github.com/repos/Releases-florperial/Super-Downloader-Manager/releases/latest`) to compare the latest version tag. No personal identifiers or system tracking data are ever transmitted.

### 4. Security
We are committed to delivering safe and transparent software. Official releases are provided with cryptographic verification hashes (MD5/SHA) so users can verify file integrity.
